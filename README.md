## 📌 About The Project

This is a classic Tic Tac Toe game where two players can play against each other on the same device.

The application includes:
- interactive game board
- turn-based gameplay
- winner detection
- game reset functionality
- responsive layout

---

## ✨ Features

- 🎲 Classic 3x3 Tic Tac Toe board
- ❌ Player X and ⭕ Player O turns
- 🏆 Winner detection
- 🤝 Draw detection
- 🔄 Restart game button
- 📱 Responsive design
- 🧩 Component-based architecture
- 🎨 CSS Modules styling

---

## 🛠 Tech Stack

- **React**
- **TypeScript**
- **CSS Modules**
- **Vite**
